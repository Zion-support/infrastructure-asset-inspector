# Infrastructure Asset Inspector

Predictive maintenance for roads, bridges, water and public infrastructure assets — computer-vision defect detection, risk scoring and maintenance scheduling.

**Free & open-source (MIT).** Part of the [Zion AI App Network](https://ziontechgroup.com/zion-app-network/) — Batch 79: GovTech & Smart City AI.

## Features
- CV defect detection from inspection photos/video
- Asset risk scoring and remaining-life estimation
- Maintenance scheduling and crew routing
- Capital-planning scenario analysis
- GIS-ready exports
